## Step 2: Modify render3DModels function (around line 106)
Replace the current render3DModels function with culling logic:

```swift
private func render3DModels(_ models: [Model]) {
    print("🎯 Graphics.render3DModels called with \(models.count) models")
    
    var visibleModels = models
    
    // Apply frustum culling if enabled
    if settings.frustumCulling {
        guard let camera = renderer.camera else {
            print("⚠️ No camera available for frustum culling")
        } else {
            let frustum = renderer.calculateViewFrustum(
                projectionMatrix: camera.projectionMatrix, 
                viewMatrix: camera.viewMatrix
            )
            
            visibleModels = models.filter { model in
                // TODO: Check if Model has boundingBox property
                // If not, you may need to check model.meshes[0].boundingBox
                // or calculate combined bounding box for all meshes
                return frustum.intersects(model.boundingBox)  // Adjust this line
            }
            
            print("🎯 Culled \(models.count - visibleModels.count) models, rendering \(visibleModels.count)")
        }
    }
    
    if !visibleModels.isEmpty {
        let pipeline = get3DPipeline()
        print("🎯 Got pipeline: \(type(of: pipeline))")
        if let vulkanPipeline = pipeline as? VulkanPipelineImpl {
            print("🎯 Successfully cast to VulkanPipelineImpl, calling render()")
            vulkanPipeline.render(models: visibleModels)  // Use filtered models
        } else {
            print("❌ Failed to cast pipeline to VulkanPipelineImpl!")
        }
    } else {
        print("❌ No models to render (after culling)!")
    }
}
```

## Step 6: Optional Distance Culling
If you want distance culling too, add this to the filter block:

```swift
// Apply distance culling if enabled
if let maxDistance = settings.maxDrawDistance {
    visibleModels = visibleModels.filter { model in
        let distance = length(model.transform.position - camera.position)
        return distance <= maxDistance
    }
}
```

## Testing
1. Run with culling enabled - should see performance improvement
2. Run with settings.debugCulling = true to see culling stats
3. Run with settings.frustumCulling = false to compare performance
4. Move camera around to see models getting culled/unculled

## Troubleshooting
- If build errors: Check Model/Mesh bounding box properties
- If no culling effect: Verify calculateViewFrustum is being called
- If wrong models culled: Check bounding box calculations and transforms
- If crashes: Add nil checks for camera and bounding boxes
